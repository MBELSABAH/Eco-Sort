# EcoSort / CarbonCraft

Public frontend (GitHub Pages):
- https://mbelsabah.github.io/Eco-Sort/

Backend (Render):
- https://eco-sort-svvs.onrender.com

## Required Render Environment Variables

- OPENAI_API_KEY
- MANAGEMENT_ID
- MANAGEMENT_KEY

Do not commit secret values.

## Deployment Notes

- GitHub Pages serves the frontend.
- Render serves the Flask backend API.
- Management login is protected by backend environment variables only.
